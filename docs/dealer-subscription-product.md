# VandLabs Dealer Subscription Intelligence

VandLabs is for used-car dealership professionals acquiring inventory for resale. Three plans — Starter, Growth, Scale — govern acquisition scope, API access and usage. The tenant retail website remains an optional sales channel.

The core journey is staff login → active subscription → capital/reserve/location → one-car or two-car strategy → evidence-based acquisition ranking → inspection and human decision → inventory → resale outcomes.

See `dealer-data-api.md` for the implemented frontend/backend path, permissions, source agreements, provider configuration, database migration, initial quotas, AI commentary and remaining live-launch dependencies. See `business-api.yaml` for the API contract. Commercial prices and automatic billing remain unconfigured; live subscriptions can be provisioned against an approved contract/invoice by a scoped platform administrator.
